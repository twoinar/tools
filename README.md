# Tools

Werkzeuge des Notariats, als Webseite unter https://twoinar.github.io/tools/.
Jedes Tool liegt in einem eigenen Unterordner und läuft vollständig im Browser.

- `erbausschlagung/` – Erbausschlagung → XNP: erstellt aus der elektronisch beglaubigten
  Abschrift einen Importordner für XNP „Sonstige Anträge“ (siehe `erbausschlagung/README.md`).
- `geldwaesche/` – Geldwäscheprüfung Kaufvertrag: liest einen Kaufvertrag und erstellt eine
  Prüfliste nach GwG und GwGMeldV-Immobilien samt Vermerk (siehe `geldwaesche/README.md`).
- `handyscan/` – Handy-Scan: Dokumente beim Vorgespräch mit dem Handy fotografieren und als PDF im
  Ablageordner auf Y: ablegen. Läuft auf dem Büro-PC im Büro-WLAN, nicht auf GitHub Pages
  (siehe `handyscan/README.md`).
- `apps/` – Übersicht der Handy-Apps mit QR-Code und Anleitung; `apps/handyscan/` leitet auf die
  Adresse des Büro-PCs weiter (dort anpassen, wenn sie sich ändert).
