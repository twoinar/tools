# Tools

Werkzeuge des Notariats, als Webseite unter https://twoinar.github.io/tools/.
Jedes Tool liegt in einem eigenen Unterordner und läuft vollständig im Browser.

- `erbausschlagung/` – Erbausschlagung → XNP: erstellt aus der elektronisch beglaubigten
  Abschrift einen Importordner für XNP „Sonstige Anträge“ (siehe `erbausschlagung/README.md`).
- `handelsregister/` – Handelsregisteranmeldung → XNP: liest die Anmeldung aus (zuerst GmbH-Geschäftsführerwechsel);
  die Importdatei folgt nach Muster-Export aus ARNOtop (siehe `handelsregister/README.md`).
